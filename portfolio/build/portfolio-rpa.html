Motor genérico de automação de interação web: adaptadores por site sobre um núcleo único, com decisão assistida por IA e evidência em imagem.

Node.jsPuppeteer 25Prisma 5.22SQLitenode --testOpenRouterAnthropic Messages API

O problema

Automação de navegador costuma nascer como script preso a um site: muda o HTML, quebra tudo, e cada novo site vira um projeto do zero. Além disso, quando a automação erra, não sobra prova do que aconteceu na tela.

A arquitetura

Node.js com Puppeteer 25 e Prisma 5.22 sobre SQLite, com 46 módulos no núcleo e adaptadores por site — o que é específico de cada site fica no adaptador, o motor de regras é comum. A decisão assistida por IA tem cadeia de fallback multi-provedor (OpenRouter, OpenAI, Anthropic, NVIDIA NIM e OpenCode Zen) sobre dois formatos de API distintos, o compatível com OpenAI e o Anthropic Messages, com fallback determinístico para quando todos falharem. Cada ação registra evidência em captura de tela, e há controle de ritmo, rede de segurança e trava de concorrência. O painel web inicia e para os ciclos.

O resultado

716 testes passando no runner nativo do Node, sem framework de teste externo.
