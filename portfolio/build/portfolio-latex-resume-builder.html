Editor de currículos em LaTeX com compilação no navegador, entregue também em variante PHP para hospedagem compartilhada.

O problema

Editar currículo em LaTeX exige instalar uma distribuição TeX de vários gigabytes, e as alternativas na web dependem de um servidor de compilação — o componente que consome CPU, exige manutenção e não cabe em hospedagem compartilhada. É por isso que serviços do tipo cobram assinatura ou limitam compilações.

A arquitetura

A decisão central é onde o LaTeX compila. Movendo a compilação para o navegador, com SwiftLaTeX gerando o PDF e Pandoc convertendo para Word, o servidor deixa de precisar de distribuição TeX, de fila de compilação e de isolamento de processo — some a parte cara e a parte perigosa de uma vez, e a aplicação passa a funcionar offline depois do primeiro carregamento. O que sobra no servidor é modesto: autenticação com bcrypt, uma API REST de documentos e um banco SQLite, que dispensa servidor de banco. Por isso a segunda variante é viável: o mesmo frontend, servido como build estático, contra um backend em PHP puro que instala em hospedagem compartilhada do jeito que um WordPress instala — enviar arquivos e apontar o domínio.

O resultado

Aplicação com dashboard de currículos, editor dividido com preview em tempo real, salvamento automático a cada dois segundos e exportação para PDF e Word, entregue em duas variantes de implantação a partir do mesmo frontend. A documentação separa o guia de instalação em hospedagem compartilhada do guia de desenvolvimento, porque são públicos diferentes com necessidades diferentes.
